# Libération du Sucre

Application pour arrêter le sucre ajouté : une graine qui devient arbre en 90 jours, un plan d'action en 21 étapes et un bilan du soir.

**Ouvrir l'application :** https://iroaimad-ops.github.io/sucre/

## Règles de croissance

Chaque bilan du soir, à partir du Jour J :

- **Aucun sucre ajouté** : la plante grandit d'un jour.
- **Un produit sucré** : la croissance s'arrête ce jour-là.
- **Craqué, beaucoup de sucre** : la plante revient au début de l'étape de croissance précédente.

Étapes : Graine (Jour J), Germe (J3), Jeune pousse (J7), Plante (J14), Fleur (J30), Arbuste (J60), Arbre (J90).

## Installer sur le téléphone

- **iPhone (Safari)** : ouvrir le lien, bouton Partager, « Sur l'écran d'accueil ».
- **Android (Chrome)** : ouvrir le lien, menu ⋮, « Installer l'application » ou « Ajouter à l'écran d'accueil ».

Les données restent sur le téléphone. Réglages du Journal : « Exporter mes données » pour garder une sauvegarde ou changer d'appareil.

## Fichiers

- `index.html` : l'application
- `manifest.webmanifest` : nom, couleurs et icônes pour l'installation
- `sw.js` : fonctionnement hors connexion
- `icons/` : icônes
